own pages are under [games/hwaoc](../games/hwaoc/README.md).

- [translation-research.md](translation-research.md): NVN to Vulkan translation research, options and progress.
- [v1.2.1-port.md](v1.2.1-port.md): Tears of the Kingdom 1.2.1 Mac port and test record (Chinese).
